# Jamiecropley Tap

## How do I install these formulae?

`brew install jamiecropley/tap/<formula>`

Or `brew tap jamiecropley/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jamiecropley/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
